Built around how a session actually goes

Pitwall drives your own claude command, so your login, settings, skills, plugins and MCP servers all carry over.

Watch

Know what every session is doing without opening it.

  • One board for everythingSessions sorted into Working, Needs you and Done today, with a live feed of recent steps, to-do progress and cost.
  • Tabs, many sessions at onceBrowser-style tabs. Closing one never stops a session; it keeps working in the background.
  • Your real historyReads Claude Code's own transcripts, so terminal sessions show up here and the other way round.
  • Only the folders you openPitwall loads just the projects you choose. Closing one hides it; nothing is deleted.

Decide

Answer Claude fast, from wherever you are.

  • Approve in one clickPermissions, questions and plans arrive as cards, with the full command or diff in view and "always allow" for what you trust.
  • Keep typing while Claude worksMessages queue up and send one at a time as each turn ends. Send one now, edit it, or take it back.
  • Switch modes from the keyboardShift-Tab steps through ask, accept edits and plan, like the terminal. Full access never hides behind a shortcut.
  • Every command, native where it countsA slash menu with your commands and skills, @ file mentions, ! shell commands and image paste.

Review

See exactly what changed, and show Claude what you mean.

  • Live changesA running diff of every file Claude edits, beside the plan, context usage and files touched.
  • Drop in screenshotsDrag images or files anywhere on the chat. Images attach; other files become @ mentions.
  • Background agents, summarizedWhen a helper agent finishes, you get a one-line result with its time, tools and tokens.
  • Private by designNo telemetry, no account, and no network connections of its own. Transcripts stay on your Mac.

Install in a minute

Requires macOS 26 (Tahoe) or later and Claude Code, installed and signed in.

  1. Download the latest .dmg and open it.
  2. Drag Pitwall onto Applications.
  3. Open it. macOS will say it can't verify the developer, because this open-source build isn't notarized. Go to System Settings, Privacy & Security and click Open Anyway.
  4. Click Choose Folder and pick a project.

Prefer the terminal? Skip the warning by clearing the quarantine flag, or build it yourself. A copy you build on your own Mac never shows the warning.

# clear the quarantine flag
xattr -dr com.apple.quarantine /Applications/Pitwall.app

# or build from source
git clone https://github.com/shijisohail/pitwall
cd pitwall && Scripts/build.sh run

Questions

Does Pitwall replace Claude Code?

No. It is a front end. Your claude command does all the work; Pitwall adds a board, tabs and one-click approvals around it.

Does it cost anything or need a separate login?

No. It is free and uses the Claude Code installation and account you already have.

Is it affiliated with Anthropic?

No. Pitwall is an independent community project. "Claude" and "Claude Code" are trademarks of Anthropic.

Is my code or conversation sent anywhere?

Pitwall makes no network connections of its own and has no telemetry. Your prompts go to Anthropic only through the claude process, under Claude Code's own terms. This website loads no trackers, fonts or scripts from other sites.

Why isn't it in the Mac App Store?

Launching your claude command and reading ~/.claude are impossible inside the App Sandbox, which the App Store requires.

Does it work on Intel Macs?

Yes. The release is universal, for Apple silicon and Intel, as long as the Mac runs macOS 26 or later.
